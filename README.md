## 它能做什么

| 说话 | 干活 |
| :--- | :--- |
| 用短句和顺口的话，少点书面腔 | “先分析”只读，“动手”按说好的范围改 |
| 清掉拔高、套话、假对比和重复 | 已经授权的事接着干，修问题先找根因 |
| 先说结论，再放需要核对的细节 | 没验证就别说修好了，没把握就照实说 |

## 安装

### 常规安装

1. 解压，保留整个 `KouYuHua-QuAiWei` 文件夹和里面的文件结构。
2. 把文件夹放进所用 Agent 的技能目录，具体位置看那个工具的设置或说明。
3. 按下面的“全局使用”，把 [AGENTS.example.md](AGENTS.example.md) 里的规则合并到所用 Agent 的全局指令中。

不支持技能文件的 Agent，直接把 `SKILL.md` 的规则放进它的全局或自定义指令。装好后开个新对话，确认规则是否加载。

### 交给 AI 安装

1. 把链接或者文件扔给AI让他自己装。
2. 按下面的“全局使用”，把 [AGENTS.example.md](AGENTS.example.md) 里的规则合并到所用 Agent 的全局指令中。

## 全局使用

把 [AGENTS.example.md](AGENTS.example.md) 的完整内容合并到所用 Agent 的全局指令里，保留已有规则。支持 `AGENTS.md` 的按其加载方式使用；其他 Agent 放进自己的全局规则或自定义指令。

示例假设技能装在 `D:\AI\skills\KouYuHua-QuAiWei`。把“完整规则文件”那一行换成自己的 `SKILL.md` 实际完整路径，再开个新对话确认。示例文件只放可复制的规则，使用方法都在这份 README 里。

核心规矩每次对话都遵守，完整技能按需读，不用每次手动调用。

## 为什么每次叫“老大”

> 这个称呼也是一个检查信号：没叫，说明这次至少漏了一条强制规矩，需要查原因；叫了，也不代表其他规矩都执行好了。

称呼可以换；长期修改时，把技能、全局规则和相关案例一起改。

## 注意事项

- **说话顺口，事实不变。** 专业词、条件和不确定程度要留住；代码、路径和报错原文不改，正式文件按需要的文体写。
- **全局使用也要守授权范围。** “先分析”就先别改，实施范围以这次明确说好的为准；案例中的数字和结论不能照搬。
- 默认用简体中文，Windows 命令规则只管 Windows。发现问题就指出具体哪句话、哪一步。
